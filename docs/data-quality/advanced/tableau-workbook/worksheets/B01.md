## Error lessons and scope

Reported build lesson: distinguish dimensions/measures from discrete/continuous. A continuous numeric ID would create a meaningless quantitative axis. Diagnostic risk: calculating MAX(SUM(D)−SUM(P),0) at wave grain can cancel opposing key discrepancies; SUM the row-level positive gap instead. Top 20 is a subset, not the full demand denominator. B05 provides broader context; do not assume the Top filter should be shared with it.

*My learning summary:* I learned to match at the smallest valid key and aggregate only after defining the discrepancy. A bar chart is useful when its ordering supports a decision, rather than simply displaying all available categories.
