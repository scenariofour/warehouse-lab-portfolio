## Question and decision

Which waves have unusual combinations of published picking volume, positive gap and gap share beyond the Top 20 list? A scatter supports comparison across two continuous magnitudes. Its business role is to select a wave for evidence inspection; an extreme point is not a diagnosed process failure or statistical outlier test.

## Data, formulas and web rebuild

[reconciliation.csv](../../public/reconciliation.csv), source grain wave/reference/size; display grain one **wave**. wave_id is a String dimension. Picking quantity and row-derived positive gap are whole-number measures; Wave Gap Share is an aggregate ratio of sums, not an average of key rates.

1. Use the [selected interpretation fields](../CALCULATION_REFERENCE.md#selected-interpretation-calculations) and Active Key=True for an equivalent rebuild. Keep the source separate from unrelated facts.
2. Create two continuous axes: Columns SUM(Positive Gap Units), Rows SUM(picking_units); Marks Circle or circular Shape. Axis placement is a reconstruction recipe; the viewer confirms both measures, not stored shelf expressions.
3. Put wave_id on **Detail** so Tableau creates wave marks rather than a single aggregate point. Color by Wave Gap Share. Keep the broader wave scope; do not inherit B01's Top 20 restriction. Exact published mark count/overplotting is not verified.
4. Tooltip: wave_id, selected customer **records**, picking units, gap units, excess units, Wave Gap Share. This field list is observed. Records are not customer-unit demand; label them accurately. Adding selected customer units would be a future tooltip change, not a documented existing field.
5. Make B05 a Select-action source and B02 the target, mapping wave_id → wave_id. The Wave drill-down was manually demonstrated (U2). Keep pInterpretation visible on the dashboard; full branch behavior remains Q1.

## Error lessons and scope

Diagnostic pattern: one dot often means a grouping dimension is missing from Detail; putting wave ID on a numeric axis does not restore meaningful wave identity. A high percentage on a tiny wave differs from a large absolute gap, so inspect both color and axes. Color has no universal failure threshold here. Source and target action roles must be explicit, and overlapping wave points may require careful selection.

*My learning summary:* I learned that the Marks card determines the analytical unit of a scatter. Color can add relative context, but a selected point still needs a detail ledger and source evidence before it supports a business conclusion.

## Three self-checks

1. **What makes one point a wave?** wave_id on Detail, with quantities aggregated across its matching keys.
2. **Is Wave Gap Share the mean of key shares?** No. It is SUM(key gaps)/SUM(selected customer units), null when the denominator is zero.
3. **Does the observed customer-record tooltip measure units?** No. Record count and requested quantity have different meanings.
